## 🛡️ L'Architecture de Sécurité (Fonctionnalités)

Ce projet repose sur une logique algorithmique stricte pour garantir une entropie maximale.

### ⚙️ Le Moteur (PasswordService)

  * **Analyse de Force en Temps Réel :** L'algorithme évalue instantanément la robustesse du mot de passe généré (Faible, Moyen, Fort).
  * **Personnalisation Totale :**
      * Longueur ajustable (8 à 30+ caractères).
      * Injection de Majuscules (`A-Z`).
      * Injection de Chiffres (`0-9`).
      * Injection de Symboles Spéciaux (`!@#$%`).
  * **UX Optimisée :** Copie dans le presse-papiers en un clic pour une friction zéro entre la génération et l'utilisation.

## 🚀 Protocole de Déploiement

Transformez votre environnement local en générateur de clés sécurisées.

### 1\. Prérequis

  * **Java JDK 8+** installé sur votre machine.

### 2\. Initialisation & Compilation

```bash
# Clonez le dépôt sécurisé
git clone https://github.com/TechNerdSam/generateurdemdp.git

# Accédez au code source
cd generateurdemdp/PasswordGeneratorApp

# Compilez le moteur (assurez-vous d'inclure les classes internes)
javac PasswordGeneratorApp.java
```

### 3\. Lancement de l'Interface

```bash
java PasswordGeneratorApp
```

*Une interface Swing native s'ouvrira, garantissant qu'aucune donnée ne transite par un navigateur web vulnérable.*
